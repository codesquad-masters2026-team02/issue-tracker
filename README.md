## 기술 스택

**Backend** — Java 21, Spring Boot 3.5, Spring Data JDBC, MySQL, Flyway, JWT, AWS S3

**Frontend** — React 18, TypeScript, Vite, TanStack Query, React Router

**Infra** — Docker, GitHub Actions, AWS (EC2, S3, CloudFront)
